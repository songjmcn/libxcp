# 测试（tests）

> 归属：`tests/`、`tests/xcp_test_slave/`、`tests/a2l_gen/`、`tests/data/`
> 本文档描述 libxcp 的测试体系、测试设施与分层策略。

## 1. 测试框架与运行

- 框架：GoogleTest v1.15.2（FetchContent；离线用 `.deps-cache/googletest/`）
- 运行（推荐 release）：

```bash
ctest --test-dir cmake-build-release -C Release --output-on-failure
```

> 不要运行 `install/Debug/bin` 下的所有测试，会导致测试时间大大增长。

## 2. 分层策略

| 层 | 载体 | 覆盖 |
|---|---|---|
| L1 单元 | `libxcp_tests` | 编解码、解码器、规划器、时间戳、错误分类（纯函数/状态机，无网络） |
| L2 mock transport | `libxcp_tests` + `tests/mock_transport.hpp` | 会话状态机、超时恢复、Master 集成（模拟链路，无真实 Socket 对端） |
| L3 集成 | `XcpliteIntegration` + `xcp_test_slave` | 真实 UDP + XCPlite Slave 子进程回环；A2L 读取与测量全链路（需 `LIBXCP_BUILD_XCPLITE_SLAVE=ON`，A2L 用例另需 `LIBXCP_BUILD_A2L=ON`） |
| A2L 专项 | `A2lSmoke` / `A2lGolden` / `A2lE2E` / `MeasurementAdapterTest` / `A2lIsolation` | 黄金回归、端到端、性能基线、依赖隔离门禁（需 `LIBXCP_BUILD_A2L=ON`） |
| L4 真 ECU | 手工冒烟 | 清单见 `code-plan/libxcp_测量子系统_v0.9_记录.md` §6 |

| `udp_test_slave_test.cpp` / `xcp_udp_loopback_test.cpp` | UDP 回环 |

### 测试设施

- `mock_transport.hpp` — L2 用 mock 传输实现
- `udp_test_slave.*` — 迷你 UDP 测试从端（与 `A2lE2E` 共享编译，测试设施非生产代码）
- `tests/xcp_test_slave/` — 基于 XCPlite 的独立 Slave 进程（`xcp_test_slave [port]`，缺省 5556）：绑定 127.0.0.1、运行时生成 A2L、注册测试变量与 Calibration Segment、主循环触发 DAQ 事件
- `tests/a2l_gen/gen_a2l.py` — A2L 黄金样本生成器（SPEC 外置 JSON，期望值独立推导不经 a2llib；`--variants` 产空白/UTF-8-BOM 变体）
- `tests/data/a2l/` — A2L 测试数据
- `tests/a2l_isolation_check.cmake` — A2L 隔离自动化（S1/S2 扫描，命中即非零退出）

### L3 / A2L 目标

- `XcpliteIntegration`：`xcplite_protocol_test` / `xcplite_write_test` /
  `xcplite_daq_test`（+ A2L 开启时 `xcplite_a2l_read_test`、
  `xcplite_measurement_test`）；Slave 路径经 CMake 注入
  `XCPLITE_SLAVE_EXECUTABLE`，禁止硬编码
- `A2lSmoke`（最小验证集，独立 main + 退出码，不依赖 GoogleTest）、
  `A2lGolden`（黄金回归 T1~T8 + T9 性能基线）、`A2lE2E`（A2L 端点自动建链 +
  变量名→地址→SHORT_UPLOAD 读值）

## 4. CTest fixture

`a2l_gen`（生成黄金 A2L，`FIXTURES_SETUP A2lGolden`）先行，`A2lSmoke` /
`A2lGolden` / `A2lE2E` 声明 `FIXTURES_REQUIRED`；性能基线由 `a2l_perf_gen`
单独提供 `A2lPerf` fixture，`ParseLargeFileUnderBudget` 单独入口避免重复计次。
生成文件只落 build tree，不入库。
