# 测量子系统（Measurement）

> 归属：`include/libxcp/measurement/`、`src/measurement/`（v1.0 冻结面之一，
> A2L-free 核心）
> 本文档描述从变量名到物理值帧回调的高级测量 API。

## 1. 模块定位

测量子系统把「A2L 变量名 → DAQ 配置 → ECU DTO → 物理值帧」全链路封装为
高级用户 API。核心只依赖窄接口 `IMeasurementDatabase` 与自有值类型，
**绝不**使用桥接层的 A2L 类型（A2lIsolation 门禁持续校验）。

```text
MeasurementSession: Add(name[]) → MeasurementPlanner（分组/装箱/路由）
    → ConfigureDaqListsDynamic 落表 → DTO 入有界队列
    → worker 线程 DtoEnvelopeDecoder → DtoPayloadDecoder
    → IMeasurementDatabase::ToPhysical → MeasurementFrame 回调
```

## 2. 组成文件

| 文件 | 职责 |
|---|---|
| `measurement_database.hpp` | 核心窄接口 `IMeasurementDatabase`（Find / ToPhysical）与符号视图 `MeasurementSymbolInfo` |
| `measurement_types.hpp` | 核心值类型（`MeasurementValue` 等） |
| `measurement_result.hpp` | 结果封装 `MeasurementResult<T>`（结构化错误，非异常路径） |
| `measurement_sample.hpp` | 单样本与帧模型（`MeasurementSample` / `MeasurementFrame`） |
| `measurement_planner.hpp` / `src/measurement/measurement_planner.cpp` | 测量规划器：`names[] → MeasurementPlan`，完成分组→装箱→路由 |
| `measurement_session.hpp` / `src/measurement/measurement_session.cpp` | 测量会话：DTO 流 → 物理值帧的高级用户 API |

## 3. 关键类型

### `IMeasurementDatabase`（核心窄接口）

- `Find(name) → MeasurementResult<MeasurementSymbolInfo>` — 按名字查布局
  （地址/扩展/事件通道/元素宽度/数量）；`name` 可为 `module::name` 规范键或
  全库唯一裸名，歧义返回 `AmbiguousName`
- `ToPhysical(name, raw) → MeasurementResult<MeasurementValue>` — 原始字节 →
  物理值；`raw` 须为**元素宽度**字节（与 `Find` 的 `element_size_bytes`
  口径一致），长度不符返回 `RawSizeMismatch`

`MeasurementSymbolInfo` 字段：`address`（32 位，AG 无关）、`extension`、
`event_channel`（仅用于规划分组）、`element_size_bytes`（单元素实占字节，
B-1 口径不除 AG）、`element_count`（首版仅标量=1）。

### `MeasurementPlanner`

输入变量名列表，输出可直接喂 `XcpMaster::ConfigureDaqListsDynamic` 的
`DaqListSpec[]` 与供 ODT Router 绑定的 `MeasurementRoute[]`
（`daq_list` + `odt` + `payload_offset` + `size` + `name`，回调按 name 索引）。

### `MeasurementSession`（最终用户 API）

- 实现 `IEventListener` 接收 DTO；**先构造 session、再以 `&session` 作
  `XcpMaster` 构造时的监听器**，`Bind(master)` 后置绑定 master 引用
- 线程模型：RX(Transport) 线程的 `OnDto` 只把完整 DTO 入**有界队列** →
  内部 worker 线程取出、以账本快照解码、换算并回调用户（回调在 worker 线程，
  非 RX 线程）
- `MeasurementStatistics`：`dto_received` / `dto_dropped`（队列溢出）/
  `decode_errors` / `timestamp_wraps`
- 时间戳语义：`SetTimestampFirstOdtOnly(true)` + `SetTimestampUnit(ns_per_tick)`
  须在 `Prepare()` 前调用（XCPlite 只对事件首 ODT 帧盖时间戳）

### 典型用法

```cpp
MeasurementSession session(database);   // 先构造（作 listener）
session.Bind(master);
session.Add("EngineSpeed");
session.Prepare();
session.Start([](const MeasurementFrame& f) { /* ... */ });
session.Stop();
```

端到端样例：`examples/measurement_demo/measurement_demo.cpp`。
