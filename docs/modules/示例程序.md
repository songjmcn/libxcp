# 示例程序（examples）

> 归属：`examples/`、`LIBXCP_BUILD_EXAMPLES=ON` 开关
> 本文档描述两个交付用示例程序的用途、流程与运行方式。

## 1. 定位与构建门

示例是**交付用可执行程序**：不进 libxcp 静态库、不是 gtest 套件、不引用
`tests/` 源码。构建开关 `LIBXCP_BUILD_EXAMPLES=ON` 时，前置依赖
`LIBXCP_BUILD_XCPLITE_SLAVE`（xcplite 库与 cpp_demo 对手端的来源）由根
`CMakeLists.txt` **自动跟随打开**，无需手工同开两门：

A2L 桥接层（`libxcp::a2lbridge`）现为必编组件，不再是示例的前置开关。

```bash
cmake -B cmake-build-release -S . -DCMAKE_BUILD_TYPE=Release \
      -DLIBXCP_BUILD_TESTS=ON -DLIBXCP_BUILD_EXAMPLES=ON
cmake --build cmake-build-release
```

## 2. `xcp_master_udp`（`examples/xcp_master_udp/`）

**独立示例**：libxcp `XcpMaster` 通过 UDP 连接 XCPlite `cpp_demo` 原样对手端。
单命令自动两轮：

1. **Run A**：在本目录拉起 `cpp_demo`（工作目录 = run-dir），首次 CONNECT 触发
   A2L 生成（`A2L_MODE_WRITE_ONCE | A2L_MODE_FINALIZE_ON_CONNECT`），确认
   `cpp_demo_V201.a2l` 落盘后终止 demo 进程
2. **桥接**：用 `libxcp::a2lbridge` 加载该 A2L，建立符号地址表
3. **Run B**：同一 run-dir 重启 `cpp_demo`（WRITE_ONCE ⇒ 复用同一 A2L），
   连接、读取默认符号集并做合理性断言；可选 `--watch` 秒级轮询动态量；
   默认执行 calseg 写回读

退出码：`0` 全部断言通过 / `1` 断言失败 / `2` 环境错误（demo 缺失、端口占用、
连接失败）。

## 3. `measurement_demo`（`examples/measurement_demo/`）

**测量子系统端到端示例**（v0.9 交付物 3）：「拉起 Slave → UPLOAD 拉回 A2L →
桥接解析 → 适配器 → MeasurementSession → 物理值帧打印」全链路，展示测量 SDK
推荐用法（与 `tests/xcplite_measurement_test.cpp` L3 同构，以交付示例形态重写）：

1. 启动 `xcp_test_slave` 子进程（工作目录 = run-dir），就绪探测 = CONNECT
2. 经 `GET_ID(IDT_ASAM_UPLOAD)+UPLOAD` 从 Slave 拉回运行时 A2L（协议面取证，
   不读盘捷径），落盘 `run-dir/uploaded.a2l`
3. `libxcp::a2lbridge` 加载上传副本 → `A2lMeasurementDatabase` 包装为
   `IMeasurementDatabase`；事件通道从 A2L MEASUREMENT 段取证，取不到时回退
   `--event`（默认 `"testev"`）的 EVENT 段通道
4. `MeasurementSession`：先构造（作 `IEventListener`）→ `Bind` → `Connect` →
   `SetEnvelopeMode(RelativeByte,4)` + `SetTimestampFirstOdtOnly(true)` +
   `SetTimestampUnit(1)` → `Add` → `Prepare` → `Start`
5. 采集 `--seconds` 秒（默认 2）：`mode=fixed` 断言首符号定标值 ==
   `--expect`（默认 `0xDEADBEEF`）；`mode=dynamic`（面向 cpp_demo 类物理值
   真实运动的 Slave，L4 冒烟口径）断言逐符号覆盖、变化性与 `--range` 值域；
   两种模式都断言解码零错误 → `Stop` → `Disconnect` → 终止 Slave

退出码同上：`0` 通过 / `1` 断言失败 / `2` 环境错误。
