# 代码结构总览（Structure）

> 归属：仓库根目录布局
> 本文档是 libxcp 目录结构的总览；各模块详细文档见本目录其余文件。

## 1. 顶层目录

```text
libxcp/
├── CMakeLists.txt              # 根构建脚本：核心库 + 4 个可选开关
├── include/libxcp/             # 公开头文件（v1.0 冻结面）
│   ├── daq/                    #   DTO 信封/净荷解码、DAQ 时间戳
│   └── measurement/            #   测量子系统（规划器/会话/数据库窄接口）
├── src/                        # 核心库实现（与 include 一一对应）
│   ├── daq/
│   └── measurement/
├── adapter/a2l/                # A2L 测量适配器（核心↔桥接层唯一接触点）
├── thirdparty/                 # 第三方依赖（只读消费，禁止手改）
│   ├── a2llib/                 #   git 子模块：上游 A2L 解析库
│   ├── a2l-sdk/                #   A2L 栈构建工程（build-sdk.ps1）
│   └── XCPlite/                #   git 子模块：Vector 开源 XCP Slave
├── tests/                      # 测试与测试设施
│   ├── a2l_gen/                #   Python 黄金 A2L 生成器
│   ├── data/a2l/               #   A2L 测试数据
│   └── xcp_test_slave/         #   XCPlite Slave 独立进程
├── examples/                   # 交付示例（xcp_master_udp / measurement_demo）
├── docs/                       # 协议规范、中文速查、模块文档（本目录）
├── code-plan/                  # 设计文档与批次实施记录（48 个 md）
├── scripts/                    # 代码质量审计脚本（Python）
└── .deps-cache/                # 离线预取 googletest 源码（可选）
```

## 3. 公开头文件清单（v1.0 冻结面）

### 协议核心（`include/libxcp/`）

`xcp_master.hpp`、`session.hpp`、`command_codec.hpp`、`response_parser.hpp`、
`command_executor.hpp`、`memory_access.hpp`、`protocol_types.hpp`、
`xcp_error.hpp`、`ixcp_transport.hpp`、`udp_transport.hpp`、
`udp_header_codec.hpp`、`udp_transport_config.hpp`

### DAQ 解码（`include/libxcp/daq/`，v1.0 冻结）

`dto_envelope_types.hpp`、`dto_envelope_decoder.hpp`、
`dto_payload_decoder.hpp`、`daq_timestamp.hpp`

### 测量（`include/libxcp/measurement/`，v1.0 冻结）

`measurement_types.hpp`、`measurement_result.hpp`、
`measurement_database.hpp`、`measurement_planner.hpp`、
`measurement_sample.hpp`、`measurement_session.hpp`

既有协议核心（`xcp_master.hpp` 等）仅追加式扩展，签名未变。封板记录：
`code-plan/libxcp_测量子系统_v1.0_封板记录.md`。

## 4. 核心数据流

```text
A2L 变量名 → MeasurementPlanner → Dynamic DAQ 配置 → ECU DTO
           → DtoEnvelopeDecoder → Timestamp/换算 → MeasurementFrame 回调
```
