## 4. 开发规范（`AGENTS.md` 摘要）

- 角色：资深 C++ / Qt 开发工程师；思考与注释使用中文
- 语言：C++20，跨平台 Windows / Linux / macOS
- 代码风格：参考 `.clang-format`
- 注释：所有接口、函数、成员函数、成员变量与全局变量需 Doxygen 格式
  **中文**注释；代码段需中文说明注释
- 测试：新修改内容需在 `tests/` 增加/更新测试用例；新接口必须配新测试
- 文档：每次修改后在 `code-plan/` 生成修改内容与测试结果（markdown）
- 代码更新纪律：已完成代码不重构、不擅自加接口；thirdparty 不得擅自修改
- git：无明确指令只允许 `git diff`、`git branch`
- 路径：禁止写死绝对路径，优先相对路径或环境变量/配置驱动
- 创造性工作前置流程：探索上下文 → 逐个澄清问题 → 分节设计并获用户批准 →
  自审设计文档；**设计批准前禁止写代码**；主动询问测试方案
