# 协议核心（Protocol Core）

> 归属：`include/libxcp/` 与 `src/` 根目录 · 命名空间 `calmcar::xcp` · C++20
> 本文档描述 libxcp 的 XCP 1.3.0 协议核心模块：会话、命令编解码、执行器、
> 内存访问、错误模型与顶层门面。

## 1. 模块定位

协议核心实现 XCP Master 侧的**协议逻辑**，与传输介质解耦（只依赖
`IXcpTransport` 抽象接口）：命令编码 → 发送 → 等待响应 → 解析 → 超时恢复
的完整闭环，以及 CONNECT 协商出的会话参数管理。

核心数据流：

```text
用户 API (XcpMaster)
    → CommandCodec     高层参数 → CTO 字节
    → IXcpTransport     发送（不感知介质）
    → ResponseParser    RES/ERR/EV/SERV/DTO 分类与字段提取
    → Session           状态机校验与参数落账
    → CommandExecutor   超时/重试/SYNCH 恢复
```

## 2. 组成文件

| 文件（`include/libxcp/`） | 实现（`src/`） | 职责 |
|---|---|---|
| `protocol_types.hpp` | `protocol_types.cpp` | 协议常量、强类型别名（`Bytes`/`BytesView`/`Address`/`AddressExtension`/`ElementCount`）、基础枚举；叶子模块，不依赖项目内其他头 |
| `xcp_error.hpp` | `xcp_error.cpp` | 统一错误分类 `ErrorCategory` 与异常 `XcpException` |
| `command_codec.hpp` | `command_codec.cpp` | 高层参数 → CTO Byte Sequence；无状态纯函数风格；reserved 填 0；多字节字段按 Session Byte Order 编码 |
| `response_parser.hpp` | `response_parser.cpp` | Packet 分类（RES/ERR/EV/SERV/DTO）与字段提取；按 Session Byte Order 解析 |
| `session.hpp` | `session.cpp` | 会话状态机（Disconnected/Connecting/Connected/Recovering/Failed）、CONNECT 协商参数、单 Outstanding Command 约束；所有公共方法加锁，线程安全 |
| `command_executor.hpp` | `command_executor.cpp` | 编码→发送→等响应→解析→超时恢复；实现 `IPacketListener`，回调在 Transport 工作线程；`CommandTimeouts`（t1..t7 由调用方提供，不宣称协议固定值） |
| `memory_access.hpp` | `memory_access.cpp` | 高层内存读：SHORT_UPLOAD 优先，必要时降级 SET_MTA+UPLOAD 分块；自动 AG 换算、分块与地址溢出检查 |
| `xcp_master.hpp` | `xcp_master.cpp` | 顶层门面，用户唯一入口；持有 Session/Executor/Transport；DA
