- 日期：2026-10-18。

## 4. 总体架构与职责

程序为独立示例，不进入 libxcp 核心库，不提供新的通用 Slave 框架。

| 部分 | 职责 |
|---|---|
| 数据模型 | 标准布局测量对象、标定对象、默认值、固定数组维度 |
| 元数据注册 | 统一定义符号名、类型、偏移、单位、范围、事件关联及标定段 |
| 模拟算法 | 读取参数快照，校验参数，计算并更新快慢测量对象 |
| 程序入口 | 解析命令行、选择互斥运行模式、文件生成、服务初始化和退出管理 |

共用的是数据定义与注册规则，不是强制两个模式执行全部相同的 A2L 写文件调用：
- 两种模式都按相同顺序创建 XCP 事件、标定段，使用相同对象布局和默认值。
- 仅生成模式初始化 A2L 写出器并发射 A2L 描述。
- 正常模式不得调用依赖未初始化 A2L 写出器的注册代码，也不创建 A2L 临时文件。
- 元数据注册在单线程初始化阶段完成，服务只在全部运行时注册成功后开放。

### 4.1 模式一：独立生成

1. 解析并校验参数及输出路径；处理覆盖策略。
2. 用本地模式初始化 XCP 内存状态，不启用持久化，不调用网络服务初始化。
3. 按固定顺序创建快/慢事件和标定段，准备默认测量对象；不执行模拟算法。
4. 初始化 A2L 生成，采用强制生成而非 WRITE_ONCE，且不使用 FINALIZE_ON_CONNECT。
5. 发射基础类型、结构体、数组、转换、分组和事件描述。
6. 手动完成 A2L，准备 AML，检查并解析完整输出。
7. 发布成功产物、释放资源、返回 0；任何失败返回非零，不转入服务模式。

### 4.2 模式二：正常服务

1. 校验参数，用相同构建标识初始化 XCP，按相同顺序创建事件和标定段。
2. 初始化测量对象及默认参数，不加载生成模式的运行状态或 BIN。
3. 启动 UDP 服务，打印端点、构建标识和事件周期。
4. 单线程以单调时钟调度快慢周期，持续更新模型并携带对应对象基址触发事件。
5. Master 自行配置动态 DAQ 表并启动采集；没有 Master 时算法仍可运行。
6. Ctrl+C 时退出循环，断开会话并关闭服务；不在退出路径生成 A2L。

## 5. 变量模型与模拟行为

### 5.1 首版覆盖范围

- 基础类型为 `int8_t`、`uint8_t`、`int16_t`、`uint16_t`、`int32_t`、`uint32_t`、`float`、`double`，测量区和标定区均覆盖全部 8 类。
- 不纳入 bool、64 位整数、枚举、位域、指针、动态容器及复杂嵌套；这些不是本轮验收内容。
- 使用标准布局、固定尺寸对象；结构布局以 `sizeof`、`offsetof` 获取，不假定编译器无填充，不依赖强制 packed 布局。
- 首版使用一维固定数组，支持按元素访问，不要求 Master 一次传完整数组。

### 5.2 建议符号清单

以下名称是后续实现的统一命名基线，A2L 语法允许的具体前缀格式在元数据核验中固定；逻辑身份不得在两种模式间改变。

| 对象 | 内容 | 分类/事件 |
|---|---|---|
| `meas_fast` | `tick:uint32_t`、`input:float`、`output:double` | 基础测量，10 ms |
| `meas_fast.state` | 计数、输入值、输出值构成的状态结构体 | 结构体测量，10 ms |
| `meas_fast.samples[8]` | `float` 固定采样数组 | 数组测量，10 ms |
| `meas_slow.basic` | 8 类基础类型的独立测试值 | 各成员为基础测量，100 ms |
| `meas_slow.statistics` | 快循环计数、输出统计、参数有效性诊断 | 结构体测量，100 ms |
| `meas_slow.history[8]` | `uint32_t` 固定统计数组 | 数组测量，100 ms |
| `cal.basic` | 8 类基础类型的独立可调测试参数 | 基础标定项，独立标定段 |
| `cal.model` | `gain`、`offset`、`lower_limit`、`upper_limit`，采用 `double` | 结构体标定，独立标定段 |
| `cal.corrections[8]` | `float` 修正系数，默认 0 | 数组标定，独立标定段 |

`cal.basic` 可以是参数容器，但其 8 个成员需分别提供可访问的标量描述；同时保留 `cal.model` 的真实结构体类型描述和实例。不得仅把全部变量展平成标量后宣称已经支持结构体。

### 5.3 确定性闭环

- 快循环以周期索引生成有界输入，例如 `input = (tick % 100) / 10.0`。
- 第 i 个采样元素的预期为 `samples[i] = input + corrections[i]`。
- 输出预期为 `output = clamp(gain * samples[0] + offset, lower_limit, upper_limit)`；默认增益 1、偏移 0、上下限 -1000/1000。
- 慢基础测量反映对应 `cal.basic` 的有效参数值，用于逐类型核对；慢统计和历史数组反映快循环结果。
- 计数及取模须避免有符号溢出；浮点比较采用类型适配的容差。
- 每次计算前检查 NaN/Inf、上下限顺序和参数范围；非法时采用明确安全值并记录诊断，不能仅依赖 A2L 中的范围声明。
- 一个周期只使用一份标定快照，不能让快照 guard 跨越等待和事件发送；写入可见性以库 RCU 契约为准，允许后续快照才生效。
- 通过多个 XCP 命令更新一组参数不保证事务性；模型要能安全处理过渡组合。

## 6. 相对寻址、A2L 与 DAQ

### 6.1 跨进程寻址

- 不记录生成进程的裸对象地址作为下一次运行的数据访问依据。
- 快慢测量分别使用自己的标准布局根对象和事件基址，A2L 内保存对应事件及成员相对偏移。
- 服务每次触发事件均传入当前进程中对应的对象基址；注册与触发使用相同的扩展基址槽。
- 标定使用标定段寻址，遵从现有 default 配置的 CASDD/ACSDD 编码，不自行假定地址扩展为 0 或手工拼装地址。
- 固定顺序：先快事件、后慢事件，再按固定顺序创建标定段；避免触发宏/链接器自动注册造成额外事件或编号漂移。
- 相对测量地址的 UPLOAD 可能依赖事件执行，服务必须持续触发事件，即使尚未启动 DAQ。相关读取测试使用有界超时，不假定任意地址都可立即同步读取。
- A2L 只适用于相同可执行构建、布局、版本及端点配置；不承诺不同平台、不同 ABI 或不同重新构建间复用。
- 构建标识发生布局/注册规则变化时必须更新；文档说明重新生成要求。不得宣称所有外部 Master 都会自动拒绝旧文件。

### 6.2 A2L 描述

- 测量项使用测量描述，参数使用标定描述；同一变量不重复作为测量和标定注册。
- 使用真实 TYPEDEF/INSTANCE 描述结构体，并验证成员偏移、类型和访问语义；数组带正确维度和元素类型。
- 测量按 fast/slow 事件分组，标定按参数段分组；不得仅凭符号前缀认定隔离已完成。
- 完整描述协议、UDP 端点、事件、类型、转换、标定段及必要的 Record Layout。
- 显式创建周期为 `10,000,000 ns`、`100,000,000 ns` 的事件，并校验 A2L 最终编码的周期/单位等价。
- A2L 和 AML 一起校验、发布；不启用库中尚未实现的 AML 内嵌分支。
- 生成失败不把不完整文件作为成功产物；优先在输出目录下的独立暂存目录生成、解析成功后发布。
- 暂存/清理/覆盖操作仅作用于本次受控产物；任何删除或移动前确认解析后的绝对目标路径，不删除用户其他文件。

### 6.3 DAQ 执行

- 保留 XCPlite 自带动态 DAQ 命令处理及 DTO 打包，不重新实现协议栈。
- 一个测量项只归属一个固定事件；快慢对象均含基础项、结构成员及数组元素，便于多事件覆盖。
- 单线程更新对象后触发对应事件，保证该事件采样点的数据已完成更新；跨事件数据不承诺原子一致快照。
- 采用单调时钟累计期限，超期时记录诊断并跳过过期节拍，避免无限追赶；不声称 10 ms/100 ms 硬实时。
- Master 根据协商到的 CTO/DTO 能力及地址扩展配置 ODT；数组及结构体按成员/元素拆分，不能假定能装入单个 DTO。
- 采集校验保留事件、计数/序列、原始字节及物理值；DAQ 不停流时验证参数写入产生效果。

## 7. 命令行与错误处理

```text
xcp_slave_demo --generate-a2l [--output-dir <dir>]
               [--bind <IPv4>] [--port <port>] [--overwrite]

xcp_slave_demo [--bind <IPv4>] [--port <port>]
xcp_slave_demo --help
```

- 默认地址 `127.0.0.1`，默认端口 `5555`；端口范围 1..65535。
- 生成模式默认输出目录为当前目录下 `a2l`；主文件名遵从 XCPlite 的项目名/EPK 规则，生成后打印实际路径，不在文档中猜测固定后缀。
- `--output-dir`、`--overwrite` 仅适用于生成模式，误用时提示参数错误；`--help` 不初始化服务或生成文件。
- 生成模式中的端点仅写入描述；不绑定端口。服务模式的端点必须与使用的 A2L 配置一致。
- 默认拒绝覆盖任一已有目标产物；`--overwrite` 仅允许替换本次主 A2L/AML，不清空整个目录。
- 输出目录不存在则创建；不可写、路径冲突、复制 AML 失败、解析失败均报告具体原因并退出。
- 建议退出码：0 成功；2 参数错误；3 产物/文件错误；4 库或元数据初始化失败；5 服务启动失败。Ctrl+C 有序退出返回 0。
- 端口占用直接报错，不自动换端口造成 A2L 不一致。
- 生成失败不退回正常运行；服务退出不顺带生成 A2L。
- 正常运行仅面向可信测试环境；无认证及测量区强制写保护，不建议直接暴露于不可信网络。

## 10. 实施阶段与风险门禁

### P0：接口与最小可行性核验

只在收到实现指令后进行。先读当前接口和 RCU/寻址文档，验证：
1. 无网络初始化即可完成所有元数据生成，产物及 AML 可完整解析。
2. 禁用持久化后，固定事件/标定段注册顺序在两种模式一致，且不隐含写 BIN。
3. 相对测量与标定段编码跨进程可用；明确上传读取等待事件的实际行为。
4. A2L 桥接能正确解析真实结构体成员/数组并提供 Master 所需元数据；不得引用旧记录的符号名和可写性结论替代验证。
5. 校验输出目录控制、生成临时文件管理及最终写失败检测确实可通过公开接口完成。

上述任一项失败：记录准确调用、错误和影响，停止受影响阶段，提出局部修订并征求批准；不得自行改 thirdparty、改用裸地址、启用持久化或取消独立生成模式。

### P1：数据模型与单元测试

落地固定类型和默认值、确定性公式、参数校验及安全降级；先完成类型、范围与边界测试。

### P2：注册与独立生成

实现固定事件、标定段、类型描述、生成 CLI、AML 交付、覆盖保护及输出校验；完成 G 系列测试。

### P3：服务及轮询测量/标定

实现 UDP 生命周期、快慢调度、相对基址事件触发及有序退出；完成 X/M/C1/C4/E 系列测试。

### P4：DAQ 与在线标定闭环

通过生成 A2L 配置双事件 DAQ，验证基本类型、复合类型、启停重连及采集中标定；完成 C2/C3/D 系列测试。

### P5：回归与交付

完成构建门、相关既有回归、平台验证、README 和实施记录；审查变更范围及第三方零修改约束。

主要风险与应对：
- A2L finalize 返回成功但写盘失败：文件完整性和解析是成功门禁，不仅看返回值。
- AML 外部引用：同目录复制资源并独立解析，不启用未实现的内嵌标志。
- ABI/版本漂移：相同构建使用、记录构建身份、布局变更重新生成。
- 链接器/宏自动注册漂移：核对事件表和标定段表，不混用产生额外描述符的便捷宏。
- 参数写入可见性延迟：按 RCU 契约获取快照，以有界样本条件确认。
- 外部 Master 不支持 TYPEDEF/地址扩展：明确兼容要求并进行定向验证，不宣称对所有工具无条件兼容。
- 当前桌面平台无法承担全平台实测：分别保留待验证项，不将未测平台记为成功。

1. 使用 `--generate-a2l` 输出 A2L/AML，确认程序退出且未监听服务端口。

4. 修改结构体增益、偏移和数组系数，观察 DAQ 输出变化，再恢复默认值。
5. 停止 DAQ、断开并有序退出；跨机使用时重新生成匹配的地址/端口配置。

## 12. 最终验收与非目标

交付必须同时满足：
- 独立程序可运行，不修改第三方库及既有示例。
- 两区分别完整覆盖基础类型、真实结构体及固定数组，且逻辑隔离。
- 显式生成模式完成后退出，不启动网络、不运行算法、不触发 DAQ；端口占用不影响生成。
- 生成产物包含必要 AML，可独立解析并用于下一次服务进程。
- 测量区的基础项、结构成员及数组元素均可按生成元数据读取并进行 DAQ；标定区的对应类型均可写入、读回并验证效果，不把标定对象混入测量区。
- 双事件采集期间标定能影响算法，且具有独立预期值和恢复验证。
- 有中文使用说明、自动化测试、实际实施记录及明确的平台证据边界。

非目标：TCP/CAN、STIM、Seed&Key、协议级测量区写保护、页切换业务演示、参数持久化、Flash 编程、动态变量注册、跨 ABI 共用 A2L、硬实时保证及商业工具全面认证。
