## 0. 写码前核证结论（§3 清单，全部工具实测）

| 核证项 | 结论 |
|---|---|
| `ProtocolLayer::GetOptionalCommands()` | 返回 `std::set<Command>`（**命令码**，与 libxcp 自有码表同源 0xFF/0xE2…）→ 计划预判的"改 string 偏差"**不需要**，§4.3 `vector<uint8_t>` 维持 |
| Daq/Event/Timestamp getter 族 | 全部可用；`GetEventList()` 字段 name/short/number/type/max_daq_list/time_cycle/time_unit/priority/consistency 确认 |
| RL 推导前提 | `Characteristic::Deposit()` 返回 RL 名字符串；`Module::GetRecordLayout(name)`；`A2lFncValue{Position,DataType,IndexMode,AddressType}`；`FNC_VALUES 0 UWORD ROW_DIR DIRECT` 合法（index_mode 表含 ROW_DIR；address_type 表含 DIRECT） |

| 上游 `/include` | `A2lScanner::FixIncludeFile` **无循环/深度/越根防护**（.a2l → 递归 ParseFile，自包含会栈溢出）→ B-18 必须由 SDK 解析前预扫描承担 |
| `LineNo()` | 解析失败路径保存 `current_lineno_`（a2lfile.cpp:289），异常路径可能为 0 → `LastErrorLine()>0 才填 Error.line` |

| TIME_UNIT 码表 | **仓库内无**（XCP 文档仅"周期=TIME_CYCLE×TIME_UNIT"）→ `cycle_time_us` 恒 0，raw 码透传，不臆造换算 |
| 主干词法大小写 | 无 `caseless` 选项 → 关键字大小写敏感 → "大小写混用"不是合法畸形，降级为 `broken_bad_keyword` 负例 |

## 5. 已知缺口与延后（诚实边界）
- **UTF-16 BOM 实测失败**：`Invalid or unsupported charset: UTF-16`（uchardet-shim/无 ICU 路径，§6.3 缺口经 T8 探索用例实证）→ 用例 SKIPPED 记录；样本统一 UTF-8/ASCII 约束维持；UTF-8 中文往返已通过。
- `EventChannelInfo.cycle_time_us` 恒 0（TIME_UNIT 码表仓库内不可得，raw 码透传；不臆造系数）。
- envelope 矩阵未覆盖 PID_OFF（实现 `DtoFrameLayout` 无该成员；B-7 部分覆盖，登记后续）。
- `CompareWithRuntime` 的 DAQ 约束类 Error 项（identification/entry granularity/addr-ext mode）**无运行时数据源**，待 10.4 DAQ 命令组落地后补比对。
- STATIC 的 WRITE_DAQ 实际账本（B-6）随 10.4；本批仅覆盖 PREDEFINED 静态解码。
- VAL_BLK/ASCII 数值执行（B-11 的另一半）延后；本批以 kUnknown+结构化拒绝锁定负例。
- T9 性能基线未测（设计即"先记录后定 SLA"）；T10 由 P9 扫描承担。
- 测试进程写系统 `%TEMP%` 被环境限制 → 深度链/UTF-16 临时文件改写 build tree（scratch_depth/、utf16_sample.a2l）。
- 生成器 `expected.json` 仅对 golden_basic 产出（人工核对用；C++ 常量为权威）。

### 7.3 用例与断言
1. **AutoLinkFromA2lEndpointConnects**：端点三件套（kind/port 0x15B9/host）来自 XcpInfo → master `Connect()` 成功且 slave.IsConnected；会话参数=8/8/Intel/Byte/0x10 + Daq 资源位 + comm_mode_info 存在 + CommandCount≥3。
2. **RuntimeConsistencyMatchesA2l**：`GetSessionParameters` → `RuntimeXcpParams`（nibble 版本转换 + 枚举映射）→ `CompareWithRuntime`：**恰 2 条 Warning（MAX_CTO/MAX_DTO：A2L 16/32 vs Slave 8/8）、0 条 Error**（BO/AG/version/DAQ 全一致）；反向 major=0x0200 → 恰 1 条 `PROTOCOL_VERSION_MAJOR` Error（B-16 运行时为真值）。
3. **ReadScalarsThroughA2lAddress**：M_UBYTE@0x3020 → ReadMemoryBytes→raw 0x2A→ToPhysical 42；M_MASK 掩码 0x0F00 提取 15；M_ARR8 整段 8 字节 raw 原样 + `ComputeElementAddress(idx3)=0x304B` 再读 1 字节=0x03（B-1 元素寻址真实往返）；**C_VALUE（RECORD_LAYOUT 推导出 UWord）→ 地址 0x3100/ext 0x12 读 2 字节 → 0x1234**（B-4 标定变量读路径端到端打通）。
4. **ReadUnconfiguredAddressThrows**：未预置地址 → `XcpException`（不静默零填）。
