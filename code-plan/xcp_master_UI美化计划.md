# XCP Master UI 美化计划

> 状态：方案已批准（m05671），实现与定向 Release/CTest 验证已完成；本文件记录设计，实施范围和验证结果见[实施记录](<xcp_master_UI美化_实施记录.md>)。人工终端交互/真实 ECU 验证未执行。

## 1. 需求与现状

用户目标：去掉重复的观测入口及底部“启动观测 / 停止 / 退出”按钮；固定为顶部状态栏、中间变量预览区域、中下部命令栏、最后快捷键提示四层。变量显示、选择和修改在预览区域内完成，命令能力仍保留。

原始实现基线（本计划提出时）：四视图纵向菜单、标定与观测区域分离、底部操作按钮及固定 18 行分页。当前已按本计划改为三个横向视图、统一变量预览和终端高度驱动的分页；实现详见[实施记录](<xcp_master_UI美化_实施记录.md>)。

说明：变量预览负责“看哪些变量、看值和编辑”，命令栏负责通用命令与采样生命周期。二者共用业务逻辑，不把所有命令再次做成一排按钮。删除按钮不删除 `watch / stop / quit`，F5 停止仍保留。截图中的背景透出可能与终端透明度有关，本计划不将其归因于 FTXUI，也不更改用户终端设置。

## 2. UI 设计与样例图

![变量预览、编辑、确认三种状态](<xcp_master_UI美化_界面样例.svg>)

[打开独立样例图](<xcp_master_UI美化_界面样例.svg>)。图中名称、地址和数值均为虚构设计数据，不表示这些变量在现有 A2L 中存在或具有写入权限；配色为示意，不是像素级验收标准。终端最终以字符单元排版。

### 2.1 固定四层

| 层 | 内容 | 布局要求 |
|---|---|---|
| 顶部状态栏 | 工具名、UDP 地址、模式及目标周期、连接/采样状态；A2L、模块、预览数与采样集合数 | 常态两行；不重复罗列全部视图名；停止采样不等于断开连接 |
| 主显示区 | 一行横向页签“变量预览 / 命令结果 / 日志”，下方为对应内容 | 占用剩余高度；只有此层随 F2 切换；不再有纵向菜单 |
| 命令栏 | `命令 >` 与单行输入框 | 固定靠底、完整宽度；保留草稿、历史和执行语义；不含三个被删除的按钮 |
| 提示栏 | 根据焦点显示 F2、Tab、Enter、Esc、F5 和翻页提示 | 最后一行；窄屏压缩文字，不挤出命令框 |

主显示区不是永久只显示变量：三个视图切换仅替换中间内容，状态栏、命令栏和提示栏始终保持。详情/编辑及写入确认均使用主显示区内的同一模态覆盖层，不在底部追加第五块。A 是完整列表常态，B 是按 Enter 临时打开的弹窗，C 是弹窗内的确认步骤；不是两个常驻区域，不并排、不压缩列表。

### 2.2 变量预览视图

- 顶部紧凑工具行：名称搜索、范围“全部候选 / 已加入采样”；不自动触发 ECU 读写。
- 中部选择表格：变量名、类型、当前物理值、单位、采样标记、状态。按模块限定名作为稳定键，显示名截断不能改变操作目标。
- “全部候选”包括 MEASUREMENT 与标量 CHARACTERISTIC/VALUE；不可读/不可写项仍可查看，明确显示原因。其他种类仍由 `list / info` 查询，不在本次扩展曲线、MAP、数组等编辑功能。
- 浏览可展示未读变量：用 `— / 未读取`，不能将未读当作 0，也不能将缓存值标成实时值。搜索仅访问 A2L 元数据，分页浏览所有匹配项，不对全库自动采样。
- 最近值按符号身份绑定：区分手动读取、采样中、已停止、读取失败；保留时间/新鲜度信息，窄屏移到详情。失败后保留旧值时显式标“旧值”，不能伪装成功。
- 变量表获得焦点并选中行后按 Enter 打开模态详情弹窗（打开本身不自动读取 ECU）：完整变量名、读写资格及拒绝原因、当前值、目标输入框、局部“读取 / 申请写入…”控件；这些是针对所选变量的操作，不是底部全局按钮。
- 详情弹窗提供“加入采样 / 移出采样”局部操作，复用 `add / remove`；不要把预览行出现与加入采样混为一谈。DAQ 活动时沿用现有修改限制并显示原因，不增加隐式重配置。
- 预览与命令入口同步：`read / write / add / remove` 的结果更新同一符号状态；`list all` 的完整目录仍在命令结果视图，不被普通 512 行结果缓存截断。

### 2.3 编辑和写入确认

1. 在表格选中符号，按 Enter 打开详情/编辑弹窗，再主动读取或查看缓存值；仅当前策略允许的标量 VALUE 显示可用写入入口。
2. 输入目标物理值，编辑本身不访问 ECU。Enter 在目标输入框只完成编辑/移动到申请控件，不直接写入。
3. 激活“申请写入…”后复用既有校验、逆换算、预读流程；通过后同一弹窗由编辑步骤进入图 C 确认步骤，不叠加第二个弹窗。展示完整符号名、当前值、目标值及单位、风险提示。
4. 默认取消；仅 Y/y 明确接受，N/n/Esc 取消；Enter 不接受，F5 取消并请求停止。确认期间阻断其他控件操作和视图切换；取消确认返回详情步骤，不发送写入；再次 Esc 才关闭详情回到列表。
5. 下发前复核一次性许可、停止状态及选择代际；成功后回读更新当前值，失败区分“未写入”“写入异常，可能部分修改”“写入成功但回读失败”。

弹窗打开期间锁定背后的搜索、列表、命令栏和 F2；Tab 焦点限制在弹窗内。关闭弹窗清空未提交目标并废弃该次编辑代际，晚到结果不得回填下一次弹窗；成功读取仍可更新同一符号的预览缓存。关闭后恢复原筛选条件、选中变量、滚动位置和表格焦点，不回到命令框、不重新搜索。之后切换变量或重新搜索仍清空旧选择状态。后台采样刷新不清空正在编辑的目标、不抢焦点。现有确认下发临界区保持不变；同步请求在途时 stop/取消可能等待，不能宣称撤回已发送请求。

### 2.4 键盘与焦点

| 按键 | 拟定行为 |
|---|---|
| F2 | 三视图循环，焦点移回命令框；不执行命令；模态弹窗期间禁用 |
| Tab / Shift+Tab | 仅遍历当前可见且可用控件；模态打开时仅在弹窗内循环，背景及其他视图不得获得焦点 |
| ↑ / ↓ | 命令框中浏览历史；变量表中选择行；输入框中不劫持为选行 |
| Enter | 命令框执行命令；搜索框应用搜索；表格打开模态详情；按钮激活；不因目标框回车而写入 |
| PgUp / PgDn | 常态翻动主显示区，模态期间仅滚动弹窗内容；不修改命令草稿；页大小由可用高度决定 |
| Esc | 确认步骤：取消并返回详情；详情步骤：丢弃草稿并关闭，恢复列表位置/焦点；无弹窗时：回命令框 |
| F5 | 保留高优先级停止；确认步骤先取消并返回详情；无需底部停止按钮 |

初始焦点为命令框。鼠标点击可作为补充但不作为必要操作路径；危险确认仍采用明确键盘接受。提示栏按焦点切换，不能在变量表聚焦时仍显示“↑↓ 命令历史”。

### 2.5 美化与尺寸适配

- 单层外边框加水平分隔线；选中行使用反色/高亮，焦点使用明确边框或标识。降低边框数量，避免大按钮耗费行数。
- 正常文字维持高对比度，青色表示选择，黄色表示待确认/旧值，红色表示错误；同时提供文字标记，不仅依赖颜色。支持终端默认颜色与无彩色降级，不用表情作为功能标记。
- 推荐尺寸 100×30 字符以上。宽度不足 100 时折叠类型、时间等次要列到详情，优先保留名称、值和状态；长名称按终端显示宽度裁剪，不按 UTF-8 字节数裁剪。
- 80×24 为最低验收尺寸：状态最多两行、命令与提示各一行，弹窗覆盖主显示区而不改变背后列表布局；详情/确认文本换行或内部滚动，完整目标不能静默裁掉。
- 小于 80×24 时保留状态、命令和“窗口过小”提示，禁用预览编辑入口；危险命令不允许在无法展示确认内容时接受。F5、取消及退出仍可用。
- 页大小依据正文区域实际高度计算，缩放时保留所选变量身份并夹紧滚动位置；命令结果/日志维持各自滚动位置。不得依赖图中像素尺寸或写死 18 行。

## 3. 实现架构与数据流（已批准并实施）

仅调整工具内部 UI/模型，不改变协议核心公共接口、CLI 参数、FTXUI 下载方式或第三方源码。

- **布局层**：四层容器、横向页签、完整预览表格和单一模态层（关闭 / 详情编辑 / 确认 / 执行结果状态）；只在 UI 线程访问 FTXUI 控件。
- **预览模型**：独立保存筛选范围、稳定选择键、可见行范围；以符号键关联最近值、来源、时间和采样成员关系。完整元数据索引与有界观测/日志分开，避免误把全库值无限缓存。
- **编辑模型**：复用现有选择代际与表单隔离，不另造绕过安全校验的写入入口。
- **命令调度**：UI 操作转成既有后台串行请求；后台结果带符号与请求代际，回 UI 后按身份合并。命令入口和预览入口共用读取/写入/采样管理流程。
- **错误处理**：元数据错误显示在主显示区；网络/协议失败在对应变量状态及日志中显示；忙时拒绝普通操作，不悄悄排队或丢掉输入。DAQ 运行期间的读取/写入限制不放宽。

拟涉及：[主界面](<../tools/xcp_master/main.cpp>)、[TUI 模型](<../tools/xcp_master/tui_model.hpp>)、[模型测试](<../tests/xcp_master_tui_model_test.cpp>)、[测试注册](<../tests/CMakeLists.txt>)、[工具说明](<../tools/xcp_master/README.md>)。如需新测试文件，放在 tests 下；是否抽出布局文件以实现阶段最小可测边界为准，不进行无关重构。

## 5. 测试与验收范围

以下为已批准的验证目标；当前自动化结果与尚未完成的人工检查见第 7 节实施状态。样例图不代替功能验收：

- 布局：100×30、120×40、80×24 以及低于最小尺寸；四层不重叠、输入/提示不被挤出、横向页签只有一份、删除按钮不在组件焦点链中。
- 导航：F2 循环三视图；隐藏控件不获焦点；不同焦点下方向键/Enter 行为正确；Enter 打开弹窗不发送读写；弹窗隔离背景键鼠事件；Esc 分层退出并恢复原搜索、选中行和滚动位置；刷新不覆盖草稿；缩放、翻页后仍能到达完整结果。
- 预览：搜索不产生 ECU 读写，预览和采样集合独立；命令与局部操作结果一致；未读/旧值/错误区分；跨模块重名使用完整键。
- 编辑：关闭弹窗/切换/搜索清草稿，关闭后立即重开同一变量也不得接收旧弹窗结果，旧读回不污染新变量；弹窗打开时不能操作背景列表或命令栏；只读或不支持项不能申请写入；命令路径仍保持同样安全规则。
- 确认：默认取消、Enter 不接受；N/n、Esc、F5、stop/退出或小窗缩放在 Dispatch 前撤销许可；原子取消只有赢得 Dispatch 边界才报告“未发送”。Dispatch 先消费许可时后续取消不阻塞UI，也不宣称能撤回在途XCP请求；模拟发送者覆盖零写入/零 FREE_DAQ、Wait后取消和Dispatch并发。
- 构建：AppleClang Release `xcp_master` 与相关模型/策略 tests 已构建；完整 XCP Master/UI 聚焦 CTest 共 42/42 通过（0失败、0跳过），包含 CLI、策略、TUI模型/确认/分页/搜索代际。本轮未执行全仓库 Release/CTest，也未将局部结果外推为全量通过。
- 人工验收建议：本机交互终端截图与键盘走查；真实 Slave 写入仍需另行授权。Windows/Linux/macOS 全平台终端验收沿用此前暂缓决定，本轮不擅自恢复。

验收核心：默认屏幕只有四层且无三个全局按钮；可在预览区选择变量并完成安全读取/标量编辑；命令功能不倒退；主显示区三视图可切换；后台刷新不打断输入；小窗口不遮蔽危险操作对象。

## 6. 自审与交付边界

- 四层是布局结构，三视图是主显示区内容，两者不冲突。
- 删除全局按钮不等于删除命令；局部读取/申请写入不是重新增加采样启动按钮。
- 预览范围不等于自动读取范围，搜索不自动加采样；写入仍仅限既有标量 VALUE 安全边界。
- 样例图覆盖正常、编辑、确认三种状态；错误、空列表和窄屏行为已有文字定义，实施后需真实截图验证。
- 用户 m05671 已批准本方案并授权实现；FTXUI 固定版本/依赖方式未改变，未改第三方源码或协议公共接口。
- 已确认：Enter 打开模态详情，取代内嵌展开；确认只以 Y/y 接受，N/n/Esc 取消、F5 取消并停止。
- 样例图是交互示意而非真实终端截图；本轮没有执行本机键盘人工走查或真实 ECU/标定写入。
