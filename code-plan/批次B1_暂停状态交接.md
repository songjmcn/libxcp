## 3. 本轮发现并修复的 4 个真实缺陷

### 缺陷 1：`ProbeVersion()` 探测成功却不让其生效

- 现象：用例 `ExplicitProbeVersionUpdatesSnapshot` 失败——调用方拿到
  `Available`，但快照仍是"未确认"，接口语义自相矛盾。
- 修复：`src/xcp_master.cpp` 中 `ProbeVersion()` 在探测成功后调用
  `ApplyVersionProbe(probe)`。

### 缺陷 2：探测超时会**中断整个 CONNECT**

- 现象：`RunCommand` 在恢复重试用尽后抛的是 `RecoveryFailed`，
  **不是** `Timeout`（`src/command_executor.cpp:978`），
  因此 `ExecuteGetVersion` 的超时分类分支永远不命中，异常直接上抛。
- 后果：一个慢对端会让 `Connect()` 直接失败，违反"探测失败必须只降级为
  未确认"的设计契约。
- 修复：`ExecuteGetVersion` 的 catch 中新增
  `ErrorCategory::RecoveryFailed → GetVersionOutcome::TimedOut` 分支。

### 缺陷 3：`Disconnect()` 后版本证据不清理

- 现象：`VersionEvidenceIsClearedOnDisconnect` 失败——断连后
  `GetProtocolVersionSnapshot()` 仍报告上一会话的 `GetVersion` 精确版本。
- 后果：调用方会据此对"已无会话"的连接做能力判断，属静默越界。
- 修复：`XcpMaster::Disconnect()` 的两个出口（已断连的幂等早返回、正常结束路径）
  均清零 `m_protocol_version_` / `m_transport_version_` / `m_version_conflicts_`。
  原 `Connect()` 起始处的清零保留作兜底。

### 缺陷 4（**既有缺陷，非本次引入**）：`Disconnect()` 后再也无法 `Connect()`

- **用户裁定 (m04241)：本轮一并修复。**
- 现象：`Connect → Disconnect → Connect` 恒定失败，抛
  `InvalidState: "当前状态不允许进入恢复: Connecting"`。
- 根因：`Disconnect()` 关闭 Transport → 触发
  `CommandExecutor::OnTransportClosed()` → 置 `m_transport_closed_ = true`；
  而 `Connect()` 重新 `Open()` 时**没有任何地方把它清回 false**。于是重连后
  第一条命令的 `WaitForResponse` 立刻看到"通道已关闭"而提前返回，
  CONNECT 超时，恢复又因会话处于 `Connecting` 而抛 `InvalidState`。
- 证据：
  - 用 `autodetect_version=false` **完全排除版本逻辑**后仍可复现
    （`Connect → Disconnect → Connect` 即失败）。
  - 该标志在提交基线 `425e6fb` 中已存在 **5 处**，本次 diff 只触及
    `m_cancelled_` 相关条件，**未引入该缺陷**。
  - `IPacketListener` 接口（`include/libxcp/ixcp_transport.hpp:26-51`）
    只有 `OnPacketReceived` / `OnTransportClosed` / `OnTransportWarning`，
    **没有**"已打开"回调，故复位必须由 `XcpMaster` 在 `Open()` 后主动发起。
- 修复进度：**进行中**（见第 4 节）

## 6. 不可违反的设计约束

1. PL 与 TL 是**两个独立维度**，禁止互相推导。
2. **不得伪造精确版本**：Minor 未确认必须表达为 `MajorOnly` + `1.x-conservative`。
3. **超时 ≠ 老版本**：探测失败只表示"未确认"，不得推断对端为 V1.3。
4. `Capped` 是**状态标志而非伪造来源**：`reported` 保留对端原值、`effective` 封顶。
5. 版本证据是**会话态**，断连/重连必须作废，不得跨会话残留。
6. 冲突**必须始终可见**，不提供静默模式。
