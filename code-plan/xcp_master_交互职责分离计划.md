## 1. 目标与边界

- 去除用户命令 `add`；观测成员由变量预览中的快捷键管理。保留 `watch` 启动、`stop` 停止以及 F5 停止入口；不解释为删除其他所有命令。
- 预览负责搜索、选择、加入/移出观测、原位展开数据及进入标定；详情只负责完整元数据和诊断，不再承担观测集合管理或混合式读写表单。
- Enter 原位展开，不再打开旧版详情/编辑弹窗。数组全部元素在展开区可滚动访问，不再使用旧版 8 项手动翻页弹窗。
- 标定独立编辑与确认，不因选择、展开或快捷键直接写入。
- 保持 C++20、Windows/Linux/macOS 目标、FTXUI tools-only FetchContent 依赖方式；不更改 submodule、协议公共 API、第三方源码，不扩大 STRUCTURE 候选范围。

## 3. 职责与数据流

### 3.1 搜索、集合和展开

1. 搜索仅查询元数据；选择、加入观测集合不访问 ECU。
2. 在变量列表有焦点且选中变量时，Ctrl+A（macOS：Command+A）切换加入/移出观测集合；重复添加不产生重复项。DAQ 活动时不隐式重配置，提示先 `stop`。编辑框保留自身全选语义。
3. `watch` 启动集合中符合策略的变量采样；`stop` 停止采样但不清空集合、展开状态和最近值。停止值明确标记“已停止/旧值”及时间。
4. Enter 切换当前变量原位展开/折叠。运行中只有展开区域显示连续观测数据；折叠仅隐藏，不停止该变量采样，不修改 ECU 配置。收起行显示类型、成员关系、能力和状态摘要，不展示数组项值。
5. 未运行时，展开不自动启动 `watch`；展开区提供“读取一次”入口及旧值/未读取状态，可手动读取但不改变采样生命周期。运行中不得绕过 DAQ 限制另发手动读请求。
6. 多变量可分别保持展开；渲染按可视窗口裁剪，使用符号完整键及元素索引定位，缩放、刷新不改变选中身份和滚动锚点。

### 3.2 数组支持与能力提示

- 当前观测入口沿用标量策略，**实现本方案必须补齐一维 MEASUREMENT 数组的观测能力**，不能仅删除拒绝文字。沿用已知固定宽度、连续步长、1–4096 元素、32 位安全范围、字节序/地址粒度检查；数组仍只读。
- 每次 POLL 周期按既有命令串行机制分块读取，保留 address extension；数组值按索引保存，带请求代际、批次及时间。完整批次成功后发布；部分失败保留上一批次并明确旧值和失败范围，不把新旧元素拼成一次完整成功。
- 展开数组生成完整索引模型，终端只渲染可视部分；128 项可经上下键/PgUp/PgDn全部到达。全量读取分块进行，可在块间响应停止；不得承诺撤回已发送请求。负载超过目标周期时显示超期，不并发堆积周期。
- DAQ 模式必须验证数组到 ODT/DTO 的元素映射、容量、事件和时间语义。超出能力时拒绝该变量加入并说明原因；不得静默截断、自动切换 POLL 或把一维分页可读等同于 DAQ 支持。数组 DAQ 能力尚未实测，不在本次文档中宣称已具备。
- 列表分别显示“手动读取能力 / 当前模式观测能力 / 标定能力”，不再使用标量观测失败原因代表所有读取。模式不支持时仍可停止采样后手动展开读取。
- 不在本轮扩大二维数组、MAP、VAL_BLK或不支持轴的曲线读取；固定轴曲线保持现有单点能力，显示明确边界。

### 3.3 详情和标定

- 预览中 F3 打开只读元数据详情：完整名、类型/维度、元素宽度、地址扩展、布局、能力及拒绝原因；Esc 返回原变量位置。详情不包含采样添加或写入控件。
- Ctrl+S（macOS：Command+S）从选中变量进入独立标定编辑；F4 为备用入口。不是保存或直接下发。
- 编辑显示完整目标、当前值及时间、单位和可写条件；只读或条件不明时显示拒绝原因，不能申请写入。仍只允许既有安全策略认可的 VALUE 标量和固定轴 CURVE 单点，数组只读。
- 申请后执行校验/逆换算/预读，再进入同一模态层的确认步骤；默认取消，仅 Y/y 接受，Enter 不接受，N/n/Esc 返回编辑，F5 取消并停止。
- 下发前复核权限、页信息、选择代际和一次性许可；回读验证，区分未发送、可能部分修改、写入成功但回读失败。保留既有 Dispatch 原子取消边界。
- 模态期间背景及快捷键失效，Tab 仅在模态内循环；关闭清草稿，恢复筛选、位置与焦点，晚到结果不得污染下一次编辑。

## 4. 命令与键盘

| 入口 | 后续行为 |
|---|---|
| Ctrl+A / Command+A | 列表焦点下切换观测成员；输入框内不劫持全选 |
| Ctrl+S / Command+S | 列表焦点下进入标定，不直接写入 |
| F6 / F4 | 分别作为成员切换 / 标定的终端兼容备用键 |
| Enter | 列表上展开/折叠；命令框执行；编辑框不直接写入 |
| F3 | 只读元数据详情 |
| ↑↓ / PgUp / PgDn | 列表或展开内容导航，全部数组索引可达 |
| F2 / Tab / Shift+Tab | 保留三视图切换与焦点导航；模态隔离 |
| Esc | 展开区返回父行；详情关闭；标定/确认按层级返回 |
| watch / stop / F5 | 启动集合采样 / 停止；F5 保持高优先级 |
| add | 从解析器、帮助、示例、空集合提示及 UI 内部文本调用移除；输入时提示改用快捷键 |
| remove | 保留既有显式移除命令兼容性，和快捷键共用集合管理逻辑 |

`list / more / info / find / read / write / quit` 等非 add 命令不因本次简化一并删除，仍遵守原安全边界。UI 添加不再通过拼接 `add` 命令实现。

### 4.1 终端兼容约束

- Ctrl+Z 方案已废弃，采用 Ctrl+S；不得保留旧提示。
- 部分 POSIX 终端 Ctrl+S 是 XON/XOFF 流控。后续实现需核验 FTXUI 实际终端模式；如需调整，仅在工具运行期间保存/恢复相关终端属性，禁止全局修改用户配置或自动执行永久 `stty` 设置。
- macOS Command 组合键可能被终端截获，不可保证应用直接识别。提示对应平台组合键，同时提供 F6/F4；按终端配置将 Command+A/S 映射为工具可接收序列。未验证的终端标记未验证，不将映射成功作为既成事实。
- 不同焦点采用不同提示；命令框输入、全选、历史不被列表快捷键抢占。功能键同样可能需要终端/Fn 配置，应在人工验收检查。

## 5. 架构、错误处理与实施顺序

本次仅实现工具内部 UI/模型和相关测试：

1. **状态模型**：分离候选目录、观测成员、展开状态、按索引样本、只读详情和标定状态；不再以“弹窗打开”代表展开。
2. **集合入口**：UI 直接调用共享集合业务；去除 add 文本入口，修正文档/帮助及空集合提示，保留 watch/stop。
3. **观测管线**：先完成数组能力校验、分块读取、完整批次发布、停止和失败状态，再接入展开显示；不修改协议核心公共接口。
4. **渲染与事件**：四层布局不变；原位展开撑占主显示区，滚动窗口保证命令栏/提示栏固定；只读详情与标定使用互斥模态。
5. **安全与隔离**：所有 FTXUI 状态仅在 UI 线程更新；结果按完整符号键、选择/请求代际、批次匹配。忙时明确拒绝，不静默丢弃输入；错误显示在对应变量展开区和日志。
6. **验证和记录**：新增/更新 tests 下模型、策略、命令和事件测试；实现后更新 README 与实施记录。第三方、SDK、协议公共 API 不做无关修改。

保留最近值需明确上限，按当前观测集合和已展开变量管理缓存；完整索引可达不等于为整个 A2L 全库无限读取/缓存。实现阶段先测量数组 128/4096 项的周期耗时，再报告实际能力。

## 8. 后续修订：功能键驱动的预览/命令交互（已实现工具内部变更）

> 本节记录用户确认的功能键交互方案与落实情况。第 3.1 节、第 3.3 节及第 4 节关于旧 Ctrl/Command/Alt 键位、F2/Tab/Esc 的文字，以及第 6–7 节的 60/60 通过记录，均为修改前的历史信息；冲突时以本节为准，旧测试成绩不代表新版已验收。图 A–D 是旧交互阶段的示意图，未重绘为新版功能键效果图。

### 8.1 目标、边界及统一键位

- 修改前：`tools/xcp_master/main.cpp` 在 `Run()` 中默认聚焦命令输入，F2 与无弹窗 Esc 也会主动将焦点移向命令输入，Tab 默认可跨容器移动。Ctrl/Command/Alt 或单键字符也可能与终端、文本输入冲突。
- 本次目标：默认在变量预览区工作，Tab 仅遍历预览内控件；所有**应用操作快捷键**统一用 F1～F12 范围内的功能键，不再用普通 `:`、Ctrl+:、`m`、`c` 或 Ctrl/Command/Alt+A/S 触发操作。Tab、方向键、Enter、Esc 仍负责导航、输入和返回，并非要替换的操作快捷键。保留既有命令执行、安全确认与 F5 停止语义；不修改 SDK、公共 API、submodule 或第三方代码。

| 键位 | 操作 | 生效条件与限制 |
|---|---|---|
| F2 | 轮换变量预览、命令结果、日志视图 | 无弹窗；不因此改变当前预览/命令模式，不自动把焦点移进命令框 |
| F3 | 打开只读 A2L 变量详情 | 变量预览中的列表聚焦且选中有效变量；不读取 ECU |
| F4 | 打开独立标定流程 | 列表聚焦且选中有效变量；仅打开表单，不直接写入 |
| F5 | 请求停止采样 | 模式无关；确认弹窗中先撤销未派发的许可再停止，已派发请求不能撤回 |
| F6 | 切换观测集合成员 | 列表聚焦且选中可观测变量；未加入时加入、已加入时移出；**不会自动启动测量**，需进入命令模式执行 `watch`；DAQ 运行时沿用现有禁止重配策略 |
| F7 | 进入命令输入模式 | 无弹窗；可从变量预览、命令结果或日志视图进入；命令模式重复按键不额外提交命令 |

F1、F8～F12 暂不绑定新功能；F2～F6 尽量保留当前程序已有的职责，F7 是新增入口。功能键可被终端、系统或笔记本 Fn/媒体键设置截获，需真实终端验证，不能宣称绝对无冲突。`watch` 与 `stop` 命令仍可使用；F6 仅修改观测成员，不等同于 `watch` 或标定写入。

### 8.2 模式、焦点与事件优先级

| 状态 | 焦点与事件 | 离开条件 |
|---|---|---|
| 预览模式（启动默认） | 初始聚焦变量列表；Tab/Shift+Tab 只在预览区搜索框、范围控件和变量列表间移动，不进入命令输入；列表焦点下 F3/F4/F6 分别打开详情、标定和切换观测成员；普通 `:`、`m`、`c` 保持文本/普通按键语义 | 无弹窗按 F7 进入命令模式 |
| 命令模式 | 命令框取得焦点；普通字符原样输入，↑/↓ 沿用命令历史，Enter 提交命令；**成功提交后仍留在命令模式**，可连续输入，忙时拒绝保留草稿 | Esc 不执行命令，返回变量预览视图并聚焦变量列表 |
| 详情／标定／确认弹窗 | 弹窗先于背景模式快捷键处理事件，Tab 不逃逸到背景；F2/F3/F4/F6/F7 不透传；确认只由 Y/y 接受，N/n/Esc 取消，F5 取消并请求停止 | 关闭后恢复发起页及发起模式；危险确认不能因焦点切换而意外执行 |

- F2 可在无弹窗时浏览三视图；预览模式浏览结果/日志时不能用 Tab 漂到命令框，F7 仍可显式进入命令模式。命令模式下 F2 只切换显示视图、仍保持命令输入焦点；Esc 明确切回变量预览和列表。
- Enter 在列表上按行种类展开/折叠或触发预览内单次读取；在搜索框按既有规则搜索，在命令框提交；标定确认不能用 Enter 接受。F5 优先级及 Dispatch 边界不变。
- 旧 Ctrl/Command/Alt+A/S 与此前讨论的 `m`/`c`、普通 `:`、Ctrl+: 不再作为目标快捷键；帮助/README 的新说明只展示功能键方案。模态内的确认字符 Y/N 和必需的导航键不受“功能键统一”影响。

### 8.3 组件调整与数据流（已按方案实现）

1. 在 `CliApp::Run()` 所属 UI 线程管理显式预览/命令模式；事件先检查模态与 F5 安全优先级，再按模式、当前视图和聚焦控件分派 F2～F7，最后交给 FTXUI 子组件。不要只靠 `TakeFocus()` 推断模式，也不要只靠根容器默认 Tab 遍历隔离命令框。
2. 启动让变量列表成为根容器活动目标；预览模式的 Tab/Shift+Tab 只遍历搜索框、范围菜单、列表。无弹窗按 F7 才切入命令输入；切换焦点不执行命令、不改变观测集合或 ECU 状态，原搜索输入 `module::symbol` 的普通冒号仍可用。
3. 命令输入 `on_enter` 仍调用原有 `SubmitCommand` 和 `CommandHistory::Commit`；成功提交后仍留在命令模式，忙时拒绝保留输入草稿。Esc 返回变量列表且不执行命令；按已确认的第 8.4 节规则，未提交草稿保留，下次按 F7 返回命令区可继续编辑。
4. F6 复用列表的 `TogglePreviewWatch()`（未加入时 Add、已加入时 Remove），F4 复用 `OpenCalibration()`；绝不因为切换成员自动调用 `watch`、读写或 FREE_DAQ。启动采样仍需命令 `watch`，F5 或命令 `stop` 停止；DAQ 锁定、写入确认与 Dispatch 边界不放宽。
5. 提示栏按模式及可用按键显示，命令区标识当前是否可输入；F2 浏览结果/日志不隐式改模式，关闭弹窗恢复发起模式。搜索代际、选择身份、异步更新和模态隔离保持现有保护。

### 8.4 功能键兼容与退出规则（已落实；终端兼容性待人工验证）

- F1～F12 在 FTXUI 有具名事件，但是否能到达程序取决于终端、OS 快捷键、键盘的 Fn/媒体键设置；不要推断 macOS、Windows、Linux 的所有终端都无冲突。F7 是**唯一规划中的命令模式键**，不再依赖 Ctrl+: 能否产生可区分的控制事件。
- F1、F8～F12 暂不绑定；旧 Ctrl/Command/Alt 组合键、`m`/`c`、普通 `:`、Ctrl+: 均不作为并行备用操作快捷键，避免同一功能有多套不一致的提示。现有 F6/F4 功能从“备用键”升为“唯一规划的成员/标定操作键”；原始文字保留在本文件前文作历史记录。
- Esc 离开命令模式时**保留未提交草稿**，重新按 F7 可继续编辑；不得自动提交或清空草稿。默认预览、Tab 边界、提交后留在命令模式、F2～F7 键位均已按用户后续实施授权落入工具内部。
