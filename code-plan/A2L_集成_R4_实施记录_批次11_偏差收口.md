## 2. 代码变更（6 文件）

### 2.1 pid_off（B-7 口径落地）
- `a2lbridge/include/libxcp/a2l/daq_layout.hpp`：`DtoFrameLayout` 补 `bool pid_off = false;`（对齐设计 §4.4:400，默认 false → 既有 31 golden/4 e2e 用例零影响）。
- `a2lbridge/src/daq_layout_impl.cpp`：`Decode` 在空帧检查后、EPK 路由前拦截 —— `pid_off==true` → `UnsupportedOperation/Phase::Layout`（理由：PID 缺席后无法按 EPK 路由，XCP 要求唯一标识由 Transport 层保证（docs §7.5/2200），UDP 里程碑无此关联通道；**绝不把净荷首字节误当 PID 解释**）。

### 2.2 include 链文本（B-18 第一步）
- `thirdparty/a2l-sdk/src/liba2l_export.cpp`：
  - 新增 `FormatIncludeChain(chain, tail)` helper（`a -> b -> a` 箭头链拼接）；
  - 循环错误：`include cycle detected: <完整链>`（替代旧的 `X (from Y)` 局部信息）；
  - 深度错误：`include depth exceeds 32: <完整链>`（链含主文件到目标的全路径）；
  - 越根错误保持 `token (from 文件)` 形式（问题在目标而非链，不在本次范围）。

### 2.3 source_lower_bound 事实化（纯注释）
- `thirdparty/a2l-sdk/include/liba2l/liba2l_api.hpp`：`DimensionDto` 注释块与成员行注明"上游词法+语法均无 ARRAY_DIMENSION/SOURCE_LOWER_BOUNDS（grep 0 命中）→ 恒 0；含该属性文件在上游 ParseFailed"。
- `a2lbridge/include/libxcp/a2l/a2l_types.hpp`：`Dimension` 同口径注记。

### 2.4 测试
- `tests/a2l_golden_test.cpp`：
  - `ExpectLoadError` 增第 5 参 `expect_include_chain`（锁"UI 能看到链"的交付面；B-19 下业务仍只判 ErrorCode）；
  - `IncludeCycleRejectedBeforeParse` 与 `IncludeDepthExceed32Rejected` 启用链文本断言（`message.find(" -> ") != npos`）；
  - `DtoEnvelopeMatrix` 尾部新增 **PID_OFF 维度负例**：`pid_off=true, header_bytes=0` + 仅净荷帧 → 断言 `UnsupportedOperation` + `Phase::Layout`。
