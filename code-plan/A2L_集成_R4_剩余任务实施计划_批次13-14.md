   每次改动在 `code-plan/` 落记录；不执行 git 提交（等明确指示）。

## 8.2 本批新发现、刻意不改的既有缺口

`CommandExecutor::m_transport_closed_` 只在析构（`command_executor.cpp:65`）与 `OnTransportClosed`（`:185`）处置
`true`，**全仓无复位点**（grep 实测）→ 同一 `XcpMaster` 上 `Disconnect → Connect` 会在 `PerformAttempt` 立即被判
超时并落入"Connecting 不允许恢复"的 InvalidState。修它要动既有恢复/状态机语义，超出批次13/14 范围，已登记为
遗留项（批次14 记录 §3.6 + 设计 §6.3），新测试 `XcpDaqSession.DisconnectKeepsLedgerButClearsRunningState`
的注释里写明"本批不测重连路径"的理由，避免留下"看起来测过"的假覆盖。
