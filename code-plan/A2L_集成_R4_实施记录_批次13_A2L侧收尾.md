### 0.1 由核证导致的计划偏差（显式登记，不静默吸收）

1. **R2（B-11 剩余）只完成 VAL_BLK 半边**，ASCII 转为"事实化拒绝"——与 B-2 `source_lower_bound`、批次11 的 `ARRAY_DIMENSION` 同一处置策略；
2. **R4 不新增线程**——原计划里"阈值回调节流"改为"按需查询"，因为上游进度 getter 存在 `scanner_` 竞争，而设计 §4.5 只承诺 `int Progress() const`，并未承诺进度回调；
3. ABI 本批一次 bump **3 → 4**，同时承载 R1（新方法 + 新 DTO）与 R4（无接口变化，仅行为变化）；R2 只改取值逻辑不动接口。

### 0.2 实施期复核：§0 的 T13-03 结论被推翻（改判为"阶段进度"）

写码前只读到"`current_lineno_`/`number_of_lines_` 均为 atomic"，实施时把两条上游实现逐行看完，发现**两条都不可用**：

| 事实 | 证据（thirdparty/a2llib，只读） |
|---|---|
| `number_of_lines_` 只在 UTF-16/32 编码分支被赋值；ASCII/UTF-8 路径恒 0 | `src/a2lfile.cpp:239-254`（`switch (encoding_)` 的 `default:` 才 `= ReadAndConvertFile(...)`） |
| 因此 `100*LineNo()/NumberOfLines()` 在**我们全部样本（UTF-8）**上是除零/无信息 | 同上 + `ProgressInfo()` 自身在 `number_of_lines_==0` 时直接返回 100（`a2lfile.cpp:423-432`） |
| `LineNo()` 内部是 `scanner_.load()->lineno()`，而 `lineno()` 读 flex 的非原子 `yylineno` | `src/a2lfile.cpp:416-421`、`src/FlexLexer.h:96` + `:104`（`int yylineno;`） |
| 更硬的问题：`scanner` 是 `ParseFile()` 的**栈对象**，解析结束即 `scanner_ = nullptr` 并析构 → 跨线程轮询存在访问已销毁对象的窗口 | `src/a2lfile.cpp:256-259`、`:269`、`:277`、`:292`、`:295` |

**结论与裁决（会话内已请示用户）**：R4 放弃"行级进度"，改为 SDK 内部 `std::atomic<int>` 的**阶段进度**——
受理=5 → `/include` 预扫描通过=25 → 上游 `ParseFile()` 返回=70 → 快照构建完成=100；
桥接层在快照发布前上限 99（发布与 `ready` 之间不得对外宣称 100，否则与 B-20"发布前不可见"矛盾），发布后恒 100。
不调用上游 `LineNo()/ProgressInfo()`（避开上述窗口），不用上游 `AsynchParseFile`（其自带线程与本类线程重复），不加监控线程。
`IDoc::Progress()` 的 doxygen 契约已改写为该语义；`LoadOptions::progress_notify_percent` 语义降为"调用方轮询节奏提示"（§4.5/B-20 同步注记见设计文档 R4.7 行）。

## 3. 边界与遗留

1. **STRUCTURE 只到"可识别"**：成员类型链不展开、无 leaf 通路、读写必拒（B-12 首版边界）；`SymbolInfo`
   不携带成员清单（成员数等派生事实写在 `description`），要 leaf 级寻址需后续独立展开器。
2. **VAL_BLK 元素数只认 `MATRIX_DIM`**：无 MATRIX_DIM 的 VAL_BLK（既有样本 `C_VALBLK`）继续拒绝，
   行为与批次10 一致；多维 VAL_BLK 统一压成**单维 extent=乘积**（连续块语义成立），整体换算仍拒
   （走 `IDaqLayout` 元素级通路）。
3. **进度是阶段量纲**，不是行比例；上游行数/`LineNo()` 不可并发使用的两条事实已写进 §0.2 与设计 §6.3，
   若将来要真实比例，需上游提供线程安全的行数/进度接口。
4. **RL 类别是 4 值粗分类**（不是 B-4 的完整字段清单）：`kPlainScalar` 之外一律不给元素类型；
   RESERVE/AXIS_PTS 之外的复合要素（DIST_OP/RIP_ADDR/SHIFT_OP/IDENTIFICATION…）统一归 `kComplex`。
5. **T9 只是基线**：预算 900 ms 由本机一次实测锁定，换机器/换盘需重标（用例失败信息里已写明重标方式）。
6. **R14（真实项目 A2L 样本）/R15（UTF-16/32）** 仍为外部阻塞，未随本批变化。
